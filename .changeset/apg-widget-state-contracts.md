Add widget contracts for `tab`, `tabpanel`, `option`, `radio`, `checkbox`, `menuitemcheckbox`, `menuitemradio` and `treeitem`. They warn when the role's required state (`aria-selected` / `aria-checked`) or accessible name is missing; an explicit `"false"` state is valid. Relationship checks that need ancestry stay out of scope.
